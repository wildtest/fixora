# FIXORA

*Tu reparación, siempre bajo control.*

Aplicación web responsive para pequeños servicios técnicos de reparación de equipos tecnológicos. Permite al taller organizar sus órdenes y al cliente consultar el estado de su reparación sin tener que preguntar.

**Estado:** En desarrollo

## Stack inicial confirmado

- Next.js (App Router)
- React
- Tailwind CSS

## Instalación

```bash
npm install
```

## Ejecución local

```bash
npm run dev
```

Abre http://localhost:3000.
